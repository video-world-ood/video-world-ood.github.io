How to read this comparison

  • Reference rail (left): Input Context clip above and Real continuation below, sized to match a grid cell.
  • Columns: Closed API models are prompted directly; Open weights models run their full component stack.
  • Rows: Zero-shot uses the baseline prompt; Detection-conditioned provides detected event/object context.
  • Timeline & durations: All clips play on one shared absolute-seconds clock. The amber notch (PNR) marks where context ends and continuation starts. Shorter clips park on their last frame (marked Ended) while longer clips finish.
